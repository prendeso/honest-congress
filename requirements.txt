# Exact versions of every runtime dependency, transitive ones included, so the
# Railway image and the GitHub Actions pipelines install the same thing twice.
#
# The direct dependencies and their allowed ranges live in pyproject.toml. This
# file used to say "Pin versions" over a list of ranges (fastapi>=0.115,<1.0 and
# so on), so every build resolved whatever was newest that day, and the image
# that shipped was never the one the tests had run against.
#
# To regenerate, on Python 3.11 in a clean virtualenv:
#   pip install .                       # resolves the ranges in pyproject.toml
#   pip freeze --exclude-editable | grep -v '^honest-congress' > requirements.lock
# then replace everything below this header with requirements.lock and run the
# test suite against it before committing.
